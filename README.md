# Portfolio de Alejandro Bedoya

Portfolio profesional desarrollado con React, Vite, Tailwind CSS y Framer Motion.

## 🚀 Características

- ✨ Diseño moderno e inmersivo con animaciones fluidas
- 📱 100% responsive
- 🌙 Tema oscuro con efectos visuales atractivos
- ⚡ Optimizado con Vite para carga rápida
- 🎨 Componentes reutilizables y bien organizados
- 🔥 Efectos de parallax y transiciones suaves

## 🛠️ Tecnologías

- **React 18** - Framework principal
- **Vite** - Build tool
- **Tailwind CSS** - Estilos
- **Framer Motion** - Animaciones
- **Lucide React** - Iconos

## 📦 Instalación

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Build para producción
npm run build

# Preview de producción
npm run preview
```

## 🌐 Despliegue

El proyecto está optimizado para desplegarse en:
- **Vercel** (recomendado)
- **Netlify**
- Cualquier servicio que soporte aplicaciones React estáticas

## 🎨 Secciones

1. **Hero** - Presentación con efectos visuales y rol dinámico
2. **Sobre mí** - Información personal y estadísticas
3. **Skills** - Stack tecnológico con barras de progreso animadas
4. **Proyectos** - Portafolio de trabajos destacados
5. **Contacto** - Formulario y redes sociales

## 📝 Personalización

Para personalizar el portfolio:

1. Actualiza la información en cada componente
2. Modifica los colores en `tailwind.config.js`
3. Reemplaza las imágenes en `src/assets/images/`
4. Ajusta las animaciones en los componentes según tus preferencias
